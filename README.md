# MindGraph

MindGraph is a personal knowledge graph application built with **C++**, **Qt/QML**, and **SQLite**.

The idea of the project is to create a visual space where notes, ideas, tasks, links, books, videos, screenshots, and plans can be connected as graph nodes.

## Planned Features

* Create, edit, and delete graph nodes
* Move nodes freely on a canvas
* Connect nodes with links
* Add different node types:
  * Notes
  * Ideas
  * Tasks
  * Books
  * Videos
  * Purchases
  * Projects
* Save data locally with SQLite
* Add tags and search
* Attach links and screenshots
* Export and import data
* Android support
* Firebase synchronization between phone and desktop

## Tech Stack

* C++
* Qt 6
* QML
* SQLite
* Firebase

## Status

The project is currently in the planning and early development stage.
